Project Overview

cortexAI is a Full Stack AI Chat & Multi-Agent Orchestration Platform built with a modern microservices architecture. Designed for high performance, modular scalability, and complex AI agent workflows, cortexAI integrates multiple LLM providers, real-time web search grounding, live code artifact previews, and server-side document generation.

Core Technical Architecture & Key Features

1. Microservices Architecture (4 Express Services)

Architected a microservices-based AI chat platform with 4 independent Express.js services (API Gateway, Auth Service, Chat Service, and Agent Service) communicating over HTTP, following a database-per-service pattern with dedicated MongoDB Atlas databases.

2. Multi-Agent AI Orchestration System (LangGraph)

Built a multi-agent AI orchestration system using LangGraph, featuring an LLM-powered intent router that dynamically dispatches requests across 6 specialized agents (chat, web search, coding, PDF/PPT generation, image generation).

3. Unified Multi-LLM Provider Integration

Integrated multiple LLM providers (Groq, OpenRouter / DeepSeek, Google Gemini) with a unified model-selection abstraction, plus Tavily API for real-time web search grounding.

4. Hybrid Authentication & Session Layer

Implemented hybrid authentication combining Firebase OAuth (Google Sign-In) with Redis-backed server-side sessions (httpOnly cookies, 7-day TTL) for secure, stateful auth beyond standard JWT.

5. Redis Memory Caching Layer

Designed a Redis caching layer for conversation memory using a sliding-window (20-message) cache-aside pattern, reducing repeated database reads and improving response latency.

6. Live Monaco Code-Artifact Preview System

Built a code-artifact generation system where AI-generated multi-file projects render live in an embedded Monaco Editor with live iframe preview rendering.

7. Document Generation & AWS S3 Delivery

Implemented server-side document generation (PDF via pdfkit, PPT via pptxgenjs) with AWS S3 storage and presigned URL delivery.
