Project Overview

Quzex is a complete, full-stack Next.js 16 agency website and content management system (CMS) built with React 19. Designed for digital agencies and high-growth platforms, Quzex features a fully customizable Admin Dashboard allowing A-to-Z control over blogs, services, portfolio cards, testimonials, client logos, and site settings, backed by MongoDB Atlas and Vercel Blob storage.

Core Technical Architecture & Key Features

1. Next.js 16 & React 19 App Router Stack

Engineered with Next.js 16.1.6 App Router, React 19.2.3, TypeScript 5, Tailwind CSS v4, and shadcn/ui v3.8.5 (New York style with Radix UI primitives). Built with Server Components for optimal initial page loads and SEO.

2. Two-Tier API & MongoDB Architecture

Designed Next.js API Routes (`src/app/api/`) into two distinct tiers: public read-only endpoints (`/api/users/*`) and secure authenticated CRUD routes (`/api/admin/*`), plus versioned APIs (`/api/v1/*`). Managed via MongoDB Atlas with 9 Mongoose models (AdminUser, Blog, BlogComment, ClientLogo, ContactInquiry, PortfolioCard, Service, SiteSettings, Testimonial) and RFC 9457 ProblemDetails error responses.

3. Full Admin Dashboard with A-to-Z Management

Built an internal admin suite enabling administrators to manage all website content seamlessly—including live blog moderation, service listings, client logos, testimonials, and site metadata—with instant Vercel Blob media uploads.

4. State Management & Data Fetching (TanStack React Query v5)

Implemented `@tanstack/react-query` v5 with optimized caching (`staleTime: 5 min`, `gcTime: 30 min`), automatic query invalidation on mutations, toast notifications via Sonner, and Server Component `initialData` passing for smooth SSR & client-side transitions.

5. Custom Authentication & Proxy Guard

Implemented a zero-dependency custom auth system featuring WebCrypto HMAC-SHA256 signed session tokens, bcryptjs password hashing, `httpOnly` cookie session storage (`quzex_admin_session`), and a `proxy.ts` middleware to protect `/dashboard` and manage API rewrites.

6. Advanced Animations & UI Utilities

Crafted smooth user interactions using Framer Motion (v12), Lucide React icons, Class Variance Authority (CVA), `next-themes` dark/light mode, and custom Tailwind animation extensions.

7. AI / LLM-Ready & Programmatic Endpoints

Built first-class AI readiness features including `/llms.txt`, `/llms-full.txt`, `/openapi.json`, programmatic `/developer` docs, markdown content-negotiation via `Accept: text/markdown` headers, and full JSON-LD structured data schemas for search engines and LLM agents.
